=== Expanded workload tagging discovery for AWS services

Workload Factory now detects more AWS services for workload tagging, expanding support for resources that can be tagged. It can now find Amazon EKS and Amazon WorkSpaces resources and include them in the tagging system so they are available for tagging.

=== Cost dashboard enhancements
The cost dashboard now includes a cost executive summary section that provides an overview of your organization's spending, helping you quickly understand and manage costs. Ask Me, the AI assistant for Workload Factory, can provide additional insights and recommendations based on your cost data. You can interact with Ask Me to get detailed explanations and suggestions for optimizing your costs. 

In addition, you can filter the cost data by one or more file systems and one or more volumes within a file system. When filters are applied, Workload Factory displays:

* Estimated total cost per month
* Estimated cost per GiB/month
* Detailed cost breakdown by service

All cost information comes directly from the AWS Cost Explorer API except for file system and volume-level cost allocation; Workload Factory estimates file system- and volume-level cost allocation.

=== Well-architected dashboard access
You can access the well-architected dashboard from the main menu in the Workload Factory console and from within a file system. To find the well-architected dashboard from the main menu, select the main menu and then select *Well-architected*.

=== New recommendations in the well-architected analysis
Workload Factory now includes the following configurations in the well-architected analysis for FSx for ONTAP file systems: 

* *Volume space management configuration*: recommends enabling coordinated volume space management for FSx for ONTAP volumes.
* *FSx integration to AWS MGN*: recommends applying the required AWS MGN readiness configuration to selected FSx for ONTAP file systems.

=== Volumes explorer enhancements
Volumes explorer is a central place in the Workload Factory console where you can view and manage all your volumes across different file systems. It provides detailed information about each volume, including its performance, usage, and protection status. The enhancements for this release include workload selection, volume latency display, and ARP/AI status for volumes.

==== Volumes explorer supports workload selection

Workload Factory selects a workload by default based on the characteristics of the volume and its usage patterns. Now you can change the workload for one or more volumes from Volumes explorer.

==== Volumes explorer displays volume latency

Volumes explorer displays volume latency status with the following statuses: not configured, within threshold, and exceeded. These statuses help you find and fix performance bottlenecks at the volume level.

==== Volumes explorer displays ARP/AI status for volumes across all file systems

The Volumes explorer screen now includes a card with NetApp Autonomous Ransomware Protection with AI (ARP/AI) status for volumes across all your file systems. The card displays the number of protected volumes and indicates whether any volumes are at risk. From the card, you can *Analyze attacks* to investigate potential ransomware threats and take appropriate actions to secure your data.

The card indicates the number of protected volumes and any volumes at risk. === Email notification for unhealthy replication relationships
When the status of a replication relationship is *unhealthy*, Workload Factory sends an email notification every 24 hours while the relationship remains unhealthy. Reminder notifications stop when the relationship returns to a healthy state.

=== Support for restricted ONTAP credentials for AIOps
Workload Factory supports two types of ONTAP credentials for an FSx for ONTAP file system: primary and restricted. By default, a file system uses the primary ONTAP credentials. We use restricted credentials only for AI operations (AIOps) like Rule builder, Custom dashboards, and Ask Me, our AI assistant. Now you can add your own credentials, using either a username and password or a secret ARN, to restrict access for AIOps features. 

link:https://docs.netapp.com/us-en/workload-fsx-ontap/manage-file-system-settings.html[Manage ONTAP credentials for an FSx for ONTAP file system]

=== Workload selection during volume creation  
Workload Factory now includes a *Workloads* field in volume creation so that you can select the workload to associate with the volume. This ensures that the volume is optimized for the intended workload from the moment it is created.

link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-volume.html[Create a volume in the Workload Factory console]

=== Cross-region host-to-storage relationship discovery

Workload Factory now supports finding connections between hosts and storage across multiple AWS regions as part of the workload tagging service. It can identify and link hosts and storage resources across regions, including mapping IP addresses between regions, so host-to-storage relationships are tagged and classified correctly.

=== Improved workload and host identification accuracy

Workload Factory now more accurately identifies and classifies workloads and hosts in the workload tagging service. Updated detection methods reduce misclassification and provide more accurate tagging and classification results.
