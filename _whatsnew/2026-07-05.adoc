=== New well-architected dashboard available
The well-architected analysis is now available for FSx for ONTAP file systems from the new *Well-architected* dashboard in NetApp Workload Factory. The new dashboard provides a centralized view of all your file systems and their configurations in one place. You'll get a popup notification to check out the new dashboard when you visit the *Well-architected* tab from a file system. 

You can still access the well-architected analysis for a specific file system and also from the menu option *Well-architected* in Storage. 

=== Volumes explorer

The new Volumes explorer gives you an estate-wide, easy-to-navigate, and easy-to-search view of your volumes in NetApp Workload Factory. You can quickly distinguish block-serving and file-serving volumes and perform the relevant operations for each volume type from one place. You can also identify which volumes are connected through host services to specific workloads, so you can understand dependencies faster and manage storage with greater confidence.
