=== Initiator group diagram enhancements    
The diagram that displays initiator groups for block devices on the Manage Client Access page now includes more details for hosts. When hovering over a host in the diagram, host details including the host name, instance ID, workload type, region, and iSCSI Qualified Name (IQN) appear. 

=== Cost dashboard enhancements
The cost dashboard now includes a cost executive summary section that provides an overview of your organization's spending, helping you quickly understand and manage costs. Ask Me, the AI assistant for Workload Factory, can provide additional insights and recommendations based on your cost data. You can interact with Ask Me to get detailed explanations and suggestions for optimizing your costs. 

In addition, you can filter the cost data by one or more file systems and one or more volumes within a file system. When filters are applied, Workload Factory displays:

* Estimated total cost per month
* Estimated cost per GiB/month
* Detailed cost breakdown by service

All cost information comes directly from the AWS Cost Explorer API except for file system and volume-level cost allocation; these costs are estimated by Workload Factory.

=== New recommendations in the well-architected analysis
Workload Factory now includes the following configurations in the well-architected analysis for FSx for ONTAP file systems: 

* *Connect host to failover node*: checks whether hosts are connected to the failover node in an active-passive FSx for ONTAP file system and suggests connecting hosts to the failover node for reliability.
* *Connect host to preferred node*: checks whether hosts are connected to their block devices using the preferred node and suggests connecting hosts to the preferred node for performance efficiency.
* *Volume space management configuration*: recommends enabling coordinated volume space management for FSx for ONTAP volumes
* *FSx integration to AWS MGN*: recommends applying the required AWS MGN readiness configuration to selected FSx for ONTAP file systems

=== Volumes explorer enhancements
Volumes explorer is a central place in the Workload Factory console where you can view and manage all your volumes across different file systems. It provides detailed information about each volume, including its performance, usage, and protection status. The enhancements for this release include workload selection, volume latency display, and ARP/AI status for volumes.

==== Volumes explorer supports workload selection

Workload Factory selects a workload by default based on the characteristics of the volume and its usage patterns. Now you can change the workload for one or more volumes from Volumes explorer.

==== Volumes explorer displays volume latency

Volumes explorer displays volume latency status with the following statuses: not configured, within threshold, and exceeded. This helps you find and fix performance bottlenecks at the volume level.

==== Volumes explorer displays ARP/AI status for volumes across all file systems

The Volumes explorer screen now includes a card with NetApp Autonomous Ransomware Protection with AI (ARP/AI) status for volumes across all your file systems. The card displays the number of volumes that are protected and if any volumes are at risk. From the card, you can *Analyze attacks* to investigate potential ransomware threats and take appropriate actions to secure your data.

Users can select the text Analyze attacks to investigate suspected attacks and take appropriate actions to secure their data.]

=== Email notification for unhealthy replication relationships
When the status of a replication relationship is *unhealthy*, Workload Factory will send an email notification every 24 hours while the relationship remains unhealthy. Reminder notifications will stop when the relationship returns to a healthy state.

=== Support for restricted ONTAP credentials for AIOps
Workload Factory now supports two types of ONTAP credentials for an FSx for ONTAP file system: primary and restricted. By default, a file system uses the primary ONTAP credentials. You can optionally add a restricted credential set, using either a username and password or a secret ARN, and update either credential set at any time.

Restricted credentials are used only for AIOps features like Rule builder and Custom dashboards. If you have not provided restricted credentials for a file system, Workload Factory creates read-only ONTAP credentials to use as the restricted credential set. If you have already provided restricted credentials for a file system, those credentials are used for AIOps feature operations.

link:https://docs.netapp.com/us-en/workload-fsx-ontap/manage-file-system-settings.html[Manage ONTAP credentials for an FSx for ONTAP file system]

Workload Factory now reminds you to complete link association after credentials have been successfully added. While credentials enable resource discovery, advanced ONTAP features require link association with the discovered file systems. You'll receive the email notification once a week on Monday. After you complete the link association, the notifications will stop.
