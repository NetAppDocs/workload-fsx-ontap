= Implement well-architected FSx for ONTAP file system configurations
:icons: font
:imagesdir: ./media/

[.lead]
Using configuration analysis insights and recommendations, leverage Workload Factory to implement best practices for your FSx for ONTAP file systems. You can easily review the well-architected status, learn about issues with your configurations, and take action to improve the architecture of any systems that aren't optimized for reliability, security, efficiency, performance, and cost.

You can also dismiss the analysis of specific storage configurations that don't apply to your storage environment to avoid unnecessary alerts and inaccurate optimization results.

link:configuration-analysis.html[Learn about the configuration analysis and well-architected status.]

== About this task
Workload Factory analyzes Amazon FSx for NetApp ONTAP file system deployment configurations daily. The daily analysis provides the well-architected status, and insights and recommendations with options to automatically fix configuration issues so that your file system meets best practices. 

Link connectivity allows Workload Factory to scan for issues with performance, data protection, and configurations. link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-link.html[Connect to an FSx for ONTAP file system using a link] for the most comprehensive analysis of your file system resources.

You have options to review the recommendations for configuration issues with your file systems and fix the issues. 

Because requirements for storage configurations vary, you can dismiss the analysis of specific configurations that don't apply to your storage environment. This helps you avoid unnecessary alerts and inaccurate optimization results. 

.What is analyzed
Workload Factory analyzes the well-architected status of the following configurations for FSx for ONTAP file systems:

* Reliability: volume backups, snapshot policy, cross-region replication, SSD capacity headroom, replication policy labels, and file object capacity
* Security: Ransomware Protection (ARP/AI) and unauthorized iSCSI volume access
* Operational excellence: automatic capacity management, volume file capacity headroom, FlexCache write mode, FlexCache replica size, host-visible capacity reporting, OS type, block device space management, and thin provisioning
* Cost optimization: cold data tiering, storage efficiencies, backup expiration, snapshot expiration, inactive block devices, overprovisioned SSD capacity, and inactive NAS volumes
* Performance efficiency: FlexGroup volumes rebalance and FlexVol volumes rebalance

== Before you begin

* You must link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html[grant _operations and remediation_ permissions^] in your AWS account. 
* link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-link.html[Connect to an FSx for ONTAP file system using a link] for the most comprehensive analysis of your file system resources.

== Fix a configuration issue
You can fix configuration issues for an FSx for ONTAP file system or for selected volumes in a file system. You can select one or more configurations to fix.

Fix operations can cause instance downtimes or service interruptions. Review each recommendation carefully before fixing a configuration issue.

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Well-architected*.
. Select *View and fix* for any configuration. Make sure you review the recommendation carefully. 
+ 
The recommendation explains best practices and potential pitfalls of unoptimized configurations.
. Select resources and then *Fix*.
+
Some fix operations are only available for specific operations and not always for more than one resource. For example, you might be able to fix the configuration for a single volume but not for multiple volumes.
. Review the information about the fix operation for the configuration in the dialog. Some operations can cause instance downtimes or service interruptions. 
. Select *Fix* if you want Workload Factory to apply the recommended changes. 

.Result
The fix process starts. Select the account settings menu and then select *Tracker* to view the status of the operation.

== Dismiss a configuration analysis
Stop a configuration analysis indefinitely for one or more resources. You can restart the analysis when needed.

Dismiss to stop configuration analysis for one or more FSx for ONTAP file systems or volumes. You can restart the analysis anytime.
 
[role="tabbed-block"]
====

.Dismiss a configuration analysis for configurations
--

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Well-architected*.  
. Under Configurations, identify the configuration that doesn't apply to your environment.
. Select image:icon-action.png[the actions menu icon] and then select *Dismiss*.
. In the Dismiss configuration dialog, select *Dismiss* to stop the analysis for the configuration.
--

.Dismiss a configuration analysis for your resources
--

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Well-architected*.     
. In the FSx for ONTAP well-architected dashboard, under Configurations, select the configuration that doesn't apply to your environment.
. On the configuration page, select the resource(s) to dismiss from the configuration analysis. 
+
* For one resource: select image:icon-action.png[the actions menu icon] and then select *Dismiss*.
* For multiple resources: select the resources and then select *Dismiss* next to Bulk action.
. In the Dismiss resources dialog, select *Dismiss* to stop the analysis.
--
====

.Result
Workload Factory stops the configuration analysis for selected configurations. 

== Reactivate a dismissed configuration analysis

Reactivate a dismissed configuration analysis at any time. You can select one or more configurations or resources to reactivate.

[role="tabbed-block"]
====

.Reactivate a configuration analysis for configurations
--

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Well-architected*.   
. Select *Dismissed configurations*. 
. Identify the configuration(s) you want to reactivate and select *Reactivate*.  

--
.Reactivate a configuration analysis for your resources
--

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Well-architected*.  
. In the FSx for ONTAP well-architected dashboard, under Configurations, select the configuration that doesn't apply to your environment.
. On the configuration page, select *Dismissed configurations*. 
. Select the resource(s) to reactivate. 

* For one resource: select image:icon-action.png[the actions menu icon] and then select *Reactivate*.
* For multiple resources: select the resources and then select *Reactivate* next to Bulk action.

--
====

.Result
Workload Factory reactivates the configuration analysis and runs a new analysis every day.
