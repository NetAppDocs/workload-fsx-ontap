= Set volume latency thresholds in NetApp Workload Factory
:icons: font
:imagesdir: ./media/

[.lead]
Set latency thresholds for volumes to receive alerts when read or write latency exceeds specified values.

.About this task
You can configure latency thresholds on a per-volume basis to monitor performance and receive alerts when latency values exceed your defined limits. Workload Factory monitors both read and write latency and generates alerts when either threshold is exceeded.

When you set latency thresholds, Workload Factory monitors the following:

* *Read latency*: Triggers an alert when read operations exceed the specified threshold in milliseconds.
* *Write latency*: Triggers an alert when write operations exceed the specified threshold in milliseconds.

Latency monitoring uses the following default parameters:

* *IOPS threshold*: 100 IOPS (read and write)
* *Time range*: 10 minutes

An alert is generated when the latency threshold is exceeded and the IOPS threshold is met over the specified time range.

NOTE: You can view latency events and receive alerts without a link connection. However, to analyze events and receive AI-powered insights and recommendations, you must link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-link.html[connect to the file system using a link].

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Storage*.
. From the Storage menu, select *FSx for ONTAP*. 
. From *FSx for ONTAP*, select the actions menu of the file system with the volume to configure and then select *Manage*.
. From the file system overview, select the *Volumes* tab. 
. From the Volumes tab, select the actions menu of the volume to set latency thresholds for. 
. Select *Alerts actions*, then *Set latency threshold*.
. In the Set latency threshold dialog, configure the following:
.. *Read latency*: Enter the threshold value in milliseconds (ms) for read operations.
.. *Write latency*: Enter the threshold value in milliseconds (ms) for write operations.
. Select *Save* to apply the latency thresholds.

.Result
Workload Factory monitors the volume and generates alerts when read or write latency exceeds the configured thresholds. You can view latency events from the link:analyze-events.html[Analysis screen].
