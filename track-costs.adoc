= Track costs for your resources in NetApp Workload Factory 
:icons: font
:imagesdir: ./media/

[.lead]
Track FSx for ONTAP file system costs and usage in a consolidated view in the NetApp Workload Factory console. The cost data helps you manage budgets and optimize resources effectively. AWS Cost Explorer provides the cost data.

.About this task
Workload Factory tracks FSx for ONTAP file system costs and usage by extracting cost data from AWS Cost Explorer. You can filter cost and usage data by AWS accounts, credentials, regions, and time ranges to get detailed insights into your FSx for ONTAP resource consumption. 

AWS allocation tag keys and tag key values add an additional layer of filtering to pinpoint specific costs. A _tag_ consists of a key and a value. To filter by tag keys and tag key values, your FSx for ONTAP file systems must already have tags assigned to them. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html[Learn more about AWS allocation tags.^]

In addition to the data that appears in the Workload Factory console, you can generate cost reports for your FSx for ONTAP file system resources to share with stakeholders. The report is a downloadable PDF file.

Regardless of the time range you specify, the data displayed is based on a monthly rate.

Cost and usage data for your FSx for ONTAP file system resources is extracted from AWS Cost Explorer using the following permissions: 

* `ce:GetCostAndUsage`
* `ce:GetTags`

.Before you begin
Ensure that you meet the following requirements: 

* You must link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html[grant credentials with the _view, planning, and analysis_ permission policy^] in Workload Factory to track FSx for ONTAP costs.
* To filter by AWS allocation tags, ensure that your FSx for ONTAP file systems have tags assigned to them.

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Storage*.
. From the Storage menu, select *Cost*.
. On the Cost page, filter cost and capacity data for your FSx for ONTAP resources by providing the following:
.. *AWS accounts*: Select the accounts you want to view cost data for.
.. *Credentials*: Select credentials with _view, planning, and analysis_ permissions.
.. *Regions*: Select the AWS regions you want to view cost data for.
.. *Cost data range*: Select the time range for cost data to view.
.. *Allocation tag key*: (Optional) Select an allocation tag key and its value to generate a detailed cost report for all FSx for ONTAP file systems associated with the AWS tag.
.. *Allocation tag values*: (Optional) Select the allocation tag key value that is associated with the allocation tag key to generate a detailed cost report for all FSx for ONTAP file systems associated with the AWS tag.
. View the *Cost Details* for your FSx for ONTAP resources.
