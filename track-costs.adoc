= Track costs and get reports for resources in NetApp Workload Factory 
:icons: font
:imagesdir: ./media/

[.lead]
NetApp Workload Factory provides a consolidated view of your FSx for ONTAP file system costs and usage, helping you manage budgets and optimize resources effectively. You can also generate cost reports for your FSx for ONTAP file system resources to share with stakeholders.

== About this task
Workload Factory tracks FSx for ONTAP file system costs and usage by getting cost data from AWS Cost Explorer. The following cost details are tracked: usage type, usage SKU, deployment type, usage, and total cost. 

For unique resources, Workload Factory calculates costs by combining the actual performance tier usage, a proportional share of performance tier costs allocated to provisioned but unused space, performance allocations distributed by capacity, and capacity pool usage. Workload Factory multiplies each component by its price per unit for that dimension and sums the results to determine the total cost for each resource.

In the Cost dashboard, you can filter cost and usage data by AWS accounts, credentials, one or more regions, and time ranges so that you can understand your FSx for ONTAP file system consumption. Workload Factory always shows data at a monthly rate. You can also filter by one or more file systems and one or more volumes within a file system. AWS cost allocation tag keys and tag key values add an additional layer of filtering to pinpoint specific costs. A _tag_ consists of a key and a value. To filter by tag keys and tag key values, assign tags to your FSx for ONTAP file systems. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html[Learn more about AWS cost allocation tags.^]

Workload Factory gets cost and usage data for your FSx for ONTAP file system resources from AWS Cost Explorer using the following permissions: `ce:GetCostAndUsage` and `ce:GetTags`. We calculate the total cost using the AWS cost API and our own estimates.

In addition to the cost data in the Cost dashboard, the cost executive summary shows your FSx for ONTAP file system costs and your organization's spending patterns. You can also generate cost reports for your FSx for ONTAP file system resources. The report is a downloadable CSV file that you can share with stakeholders. 

== Track costs
The costs shown in the Workload Factory console in the Cost dashboard are based on the data from AWS Cost Explorer, which is updated every 24 hours. 

.Before you begin
Verify that you meet the following requirements: 

* You must link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html[grant credentials with the _view, planning, and analysis_ permission policy^] in Workload Factory to track FSx for ONTAP costs.
* To filter by AWS allocation tags, verify that your FSx for ONTAP file systems have tags assigned to them.

.Steps
. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to workloads like storage, eda, ai, databases, vmware, and administration.] and then select *Storage*.
. From the Storage menu, select *Cost*.
. From the Cost dashboard, filter cost and capacity data for your FSx for ONTAP resources by providing the following:
.. *AWS accounts*: Select the accounts you want to view cost data for.
.. *Credentials*: Select credentials with _view, planning, and analysis_ permissions.
.. *Regions*: Select the AWS regions you want to view cost data for.
.. *Cost data range*: Select the time range for cost data to view.
.. *Allocation tag key*: (Optional) Select an allocation tag key and its value to generate a detailed cost report for all FSx for ONTAP file systems associated with the AWS tag.
.. *Allocation tag values*: (Optional) Select the allocation tag key value that is associated with the allocation tag key to generate a detailed cost report for all FSx for ONTAP file systems associated with the AWS tag.
. View the *Cost Details* for your FSx for ONTAP resources.

== Generate cost reports for your FSx for ONTAP resources
Generate cost reports for specific FSx for ONTAP file system resources to share with stakeholders. 

.Steps
. In the Cost dashboard, select *Generate report*.
. In the Report screen, provide the following information:
.. *File system*: Select one or more FSx for ONTAP file systems to include in the report.
.. *Volume*: (Optional) Select one or more volumes to include in the report.

.Result
A CSV report is generated and can be downloaded.
