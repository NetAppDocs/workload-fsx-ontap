= Apply ONTAP-level tags to block devices in NetApp Workload Factory
:icons: font
:imagesdir: ./media/

[.lead]
Use a native EC2 user data script to automate block device tagging on your AWS EC2 instances. Automation happens when you add the EC2 user data script to the Launch Wizard from the AWS Console for EC2 instance deployment. After deployment, NetApp Workload Factory uses the metadata collected from the script to apply ONTAP-level tags to your block storage devices. The tags help you simplify organizing and categorizing your block storage resources for FSx for ONTAP file systems.
